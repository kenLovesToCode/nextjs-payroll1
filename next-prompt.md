## Task: Employee Attendance

Build a personal attendance history view for the **Employee Role**.

**DESIGN SYSTEM (REQUIRED):**

### Visual Theme & Atmosphere

The Employee interface feels **welcoming, spacious, and airy**. Use **Vivid Neon Green (#13ec5b)** as the primary brand color against a **Mint-Tinted Off-White (#f6f8f6)** background.

### Components

- **Buttons:** Highly rounded or pill-shaped (`rounded-2xl` or `rounded-full`). Primary buttons feature a soft shadow (`shadow-primary/20`).
- **Cards:** Generously rounded corners (`rounded-xl` / 1.5rem) with thin borders (`border-primary/10`).
- **Typography:** Extra bold headers with tight letter spacing.

**Page Structure:**

1. Header: Same as Employee Dashboard (Logo, Navigation, Profile Avatar).
2. Title: "My Attendance" with current month/year selector.
3. Summary Stats: Total Present, Total Absent, Late Arrivals.
4. Attendance Table: Date, Clock In, Clock Out, Total Hours, Status (Present/Absent/Late).
5. Footer: Standard links.
